M-018 | Continual Harness (definition) | LLM Refiner edits harness H from the most recent trajectory window during a single continuous episode; generalizes reset-based prompt optimization (which rewrites only p from complete-episode resets, refs [1,14]) to rewriting the full state from the trajectory so far; agent never resets | §3 (opening, before 3.2)
